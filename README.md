# Серое сердце

«Серое Сердце» — интерактивная повесть по мотивам новелл А. Грина и анимации
П. Гримо.

Репозиторий — это реализация **кроссплатформенного движка** и **игры** на нём.
Три платформы из одного исходника: Windows, Linux и Web.

Ядро — C, зависимостей у движка нет: компилятор, линкер, Make и libc. Графика —
программный фреймбуфер, нет даже слоя SDL.

## Это эксперимент

Проект — эксперимент в области **агентной разработки исключительно на бесплатных
моделях**. Движок и игра написаны агентами; человек задавал направление, принимал
решения о формате и архитектуре и оценивал результат.

## Структура репозитория

- `src/` — весь код: разбор формата, игровой рантайм, вывод и платформы.
  Платформенный слой — это пять функций и одна точка входа, по одному файлу
  `<platform>_platform.c` на платформу.
- `assets/script/` — игры.
- `assets/font/` — шрифт в собственном формате.
- `tests/` — тесты и обход графа игровых состояний.
- `tools/` — тест-раннер и инструменты на Python.
- `doc/` — спецификации форматов.
- `AGENTS.md` — правила разработки для агентов.
