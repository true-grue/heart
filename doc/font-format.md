# Font format

A baked vector font: glyph outlines already flattened to line segments. Text is a
plain, reviewable, mergeable data file, and neither the loader nor the rasteriser
knows that curves exist.

Generated by `tools/py/bake_font.py` from a TTF. fontTools and the TTF are
development-time only and never reach the game build.

    py3 tools/py/bake_font.py /usr/share/fonts/dejavu/DejaVuSans.ttf \
        assets/font/sans.font

## Grammar

```
file    = { header | glyph } ;
header  = "font"  SP int NL          ; version, currently 1
        | "upem"  SP int NL          ; font units per em
        | "bake"  SP int SP int NL   ; nominal size and tolerance x100, informational
        | "asc"   SP int NL          ; ascender in font units
        | "desc"  SP int NL          ; descender, negative
        | "line"  SP int NL          ; line height in font units
        | "glyphs" SP int NL ;       ; glyph count, informational
glyph   = "glyph" SP cp SP advance SP segcount NL , { seg NL } ;
seg     = "x0" SP "y0" SP "x1" SP "y1" NL ;
```

- Lines starting with `#` are comments, blank lines are ignored, LF or CRLF ends a line.
- `cp` is a Unicode code point, `advance` and all coordinates are font units.
- `segcount` lines follow, one edge each. `assets/font/sans.font` has 197 glyphs and
  4128 segments, about 81 KB.

## Rules the loader relies on

- **Glyphs are sorted by code point.** Lookup is a binary search, so the loader has no
  sorting code. The baker guarantees the order.
- **`x1` is never less than `x0`, and `y1` is never less than `y0`.** The winding sign
  comes from the edge direction: an edge with `y1 > y0` adds to the winding and one
  with `y1 < y0` subtracts. That is what makes counters inside letters become holes,
  with no notion of contours anywhere in the API.
- **Horizontal edges are ignored.** They cross no scanline.

## Scaling

The loader takes a pixel size and maps font units to 16.16 fixed point by dividing,
never by shifting, so negative coordinates stay deterministic. Font units have y
pointing up and the screen has y down, so the vertical axis is mirrored at load time.
Both windings flip together, which is why holes keep cancelling without correction.

One `TextFont` is bound to one pixel size. Load another for a different size.

## Curvature

The baker flattens with a tolerance expressed in pixels at the nominal bake size, so
curves below that size are smooth and above it they may facet slightly. The default is
`0.5px` at 64px. Measured cost on DejaVu Sans, 197 glyphs:

| tolerance | segments | size |
|---|---|---|
| 0.25px | 5196 | 101 KB |
| **0.5px** | **4128** | **81 KB** |
| 1.0px | 3286 | 65 KB |

Because edges are hard and unsmoothed, faceting is far less visible than it would be
with antialiasing, and the middle row of that table is the shipped default.
